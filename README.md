Coffee Shop Landing Page

Overview

This is a minimal, aesthetic, and responsive landing page designed for a coffee shop. The project focuses on clean UI/UX principles with a simple navigation structure and smooth user experience.

Pages Included

Home Page: Introduces the coffee shop with a clean and welcoming layout

Menu Page: Displays coffee items and offerings in a structured, minimal design

Contact Page: Provides a simple way for users to reach out to the coffee shop

Features

Minimal and modern UI design
Fully responsive layout for all devices
Smooth and user-friendly navigation
Focus on readability and visual balance
Clean separation of sections for better user experience

Tech Stack

HTML
CSS
Javascript

Purpose

The project is designed to demonstrate front-end development skills with a strong focus on UI/UX design, responsiveness, and aesthetic simplicity for a real-world café landing page concept.
